# 云阙 · 月门入梦

中国风巨构 Blender 场景与 30 秒六镜头短片，现已完成并按用户要求公开存档。

## 下载

请打开本仓库 Releases 中的 **v1.1-film**：
- `yunque_film_30s.mp4`：30 秒成片，含原创配乐。
- `yunque_film_master.mp4`：同片高码率版本，不是更高分辨率版本。
- `yunque_animation.blend`：已修正避障轨迹的六镜头可编辑动画工程。
- `yunque_complete_archive_v1.1.zip`：完整离线工程，包含静态模型、六镜头动画、全部参考图、场景与影片源码、渲染图、成片与高码率版、原创配乐及质量检查。
- `SHA256SUMS`：下载校验值。

主分支 `yunque_sources.zip` 包含可复现源码与分镜，不包含大模型、参考图原文件或影片。完整文件必须下载上述离线包；普通 git clone 或 GitHub 自动生成的源码 ZIP 不包含 Release 附件。历史 v1.0-model 保留早期模型归档。

## 影片规格与画面限制

30.000 秒，960×540，24 fps 输出，720 帧，H.264 视频 / AAC 音频。六镜头依次为云海全景、白衣人物背侧近景、金灯、宫殿飞檐、古木绕行、拉回全景。

原生画面以 Cycles 实际三维相机、12 fps、每帧 16 采样渲染；开场将原 7.5 秒运动加速至 5 秒。使用深度重投影时域降噪、AgX/辉光及逐镜头传统光流插帧至 24 fps，不跨剪辑点插帧。24 fps 是输出帧率，不等于原生 24 fps 渲染。

这是风格化程序化重建，仍有采样颗粒和细节差距，不宣称与 AI 参考图逐像素或 1:1 写实一致。最终片已完整解码，720 帧扫描未发现黑帧；建筑镜头避障修复后通过复核。质量检查见离线包 `megascene/film/final_qc/`。

## 离线包布局与恢复

- `megascene/v2_rev13/`：静态冻结模型与 44 个建模源文件。
- `megascene/film/`：最终六镜头动画、`storyboard_final.json`、拍摄/后期脚本、影片和配乐。
- `references/`：全部 10 张独立参考图；11 次附件中的重复主目标映射见 manifest.json。
- `renders/`：最终模型 960×540 检查图，以及第12阶段 1440×810 历史检查图，后者不是最终13阶段高清图。

使用 Blender 4.3.2 打开 `.blend`。场景无外部贴图或 VDB 依赖。保留完整相对目录，影片脚本会读取相邻 v2_rev13 模型。

重建模型：进入 `megascene/v2_rev13/` 执行：
```sh
blender -b -t 8 --python rebuild_scene.py -- --build-only
```
影片复现必须阅读 `megascene/film/README_动态六镜头.md`，包括最终第4镜头避障修复步骤；以 `storyboard_final.json` 为最终方案，原动态分镜仅为制作依赖。需要 Blender、FFmpeg、Python、NumPy、SciPy、Pillow；中文字体路径可按本机调整。缓存和中间帧可重建，不纳入公开包。

配乐为原创程序合成，30 秒、48 kHz、24-bit 双声道 WAV，无外部采样；源代码及说明在 `megascene/film/music/`。合成音色不冒充真人演奏。
