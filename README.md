# 云阙 · 中国风巨构场景

Blender 中国风幻想巨构项目：环形巨门、盘曲古树、悬浮宫阙、桥梁、瀑布与云海。参考图用于造型、构图及光线研究；成果为实际三维场景，不宣称已经做到参考图的 1:1 完美复刻。

## 当前状态

第13阶段模型已冻结，并在 Blender 4.3.2 从零重建验证通过（约 114.77 秒）。已按用户要求创建公开 GitHub 仓库；原创30秒配乐已完成，电影镜头正在制作；视频交付部分仍未完成。

## 下载与归档布局

仓库主分支提供说明、完整参考清单、附件校验清单和 `yunque_sources.zip`。模型、参考图原文件、渲染图和音乐放在 Releases 的 `yunque_model_archive.zip` 完整离线包中；单独模型与 WAV 也可下载。以下目录指离线包解压后的布局，不表示所有文件都直接存在 Git 树中。

## 目录与交付方式

- `references/`：全部用户提供的参考图，10 张独立图像；11 次附件中的重复主目标在 `references/manifest.json` 中记录。
- `source/scene/`：最终可复现建模源码，44 个源文件及哈希清单；镜头源码稍后加入。`source/music/` 包含原创程序合成配乐源码及复现说明。
- `renders/`：最终模型 960×540 检查图，以及已交付的第12阶段 1440×810 历史里程碑；后者不是最终13阶段高清图。
- 大文件建议放在同一仓库的 **Releases**：可编辑 `.blend` 工程、成片、原始配乐，以及完整离线归档。SHA-256 见仓库附件清单；成片完成后追加。

普通 `git clone` 不会自动取得 Release 附件。要完整恢复工程，请同时下载对应版本的工程附件，不要只下载 GitHub 自动生成的源码 ZIP。

## 打开与重建

制作环境为 Blender 4.3.2。下载 Release 中的 `yunque_final_scene.blend` 后可直接打开；场景不依赖外部贴图或 VDB。重复小构件部分合并为网格，植物部分使用共享数据。

从源码恢复：终端进入 `source/scene/` 后执行：

```sh
blender -b -t 8 --python rebuild_scene.py -- --build-only
```

生成该目录下的 `云阙_V2_可编辑.blend`。改用 `--preview` 将重建并输出 960×540 / 96 采样检查图。省略上述模式参数会进行全尺寸 1920×1080 渲染，耗时更长。请优先从入口重建，不要反复手动运行增量阶段。

主场景使用 Cycles、真实网格/曲线及两组实时密度网格云。当前制作环境未启用降噪；全尺寸体积渲染较慢。构图与素材是程序化参考重建，未把参考图作为最终画面的背景投影。视频渲染设置将单独记录。
